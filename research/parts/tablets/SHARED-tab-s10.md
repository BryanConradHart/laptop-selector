## User-review findings for the S10+ (r/Samsung, r/tabletcomputers, BBY reviews — synthesis, disclosed)
Praises: the DeX desktop mode with a keyboard cover is the killer feature — real multi-window desktop UI on a 12.4" AMOLED; S Pen in the box (no $199 extra like Apple) is a constant Reddit talking point vs iPad; Galaxy phone parity is excellent (Quick Share, Second Screen as PC monitor, auto-call/text relay, Smart Switch); quad AKG speakers are loud and clear; microSD slot still exists (rare); IP68 survives pool/beach season; 7 years of OS updates means it won't go stale.
Complaints: DeX is per-app — many apps refuse to go windowed (banking, some games) and there is no true desktop browser parity (Samsung Internet desktop mode helps, Chrome does not); dimming/PWM flicker at low brightness on the AMOLED bothers sensitive users; the Slim keyboard cover has NO trackpad (trackpad lives only on the pricier $299 Book Cover Keyboard); Exynos-modem Wi-Fi drops reported on some units; no headphone jack and USB-C-only audio dongle friction; tablet apps still stretched-phone-app feel in non-DeX mode; 45W "fast" charging takes ~2h to full.
Calibration note: no pro numeric score exists to anchor against, so ratings come from measured-spec consensus (AMOLED, ~14h+ NBC-style Wi-Fi-web runs, ~10h heavy mixed) tempered by heavier user complaints about DeX's per-app windowing limits than launch reviews emphasized: productivity and ecosystem are set at the LOW end of what the hardware justifies (ecosystem ~7 — DeX + Galaxy-phone parity genuinely strong, but Android tablet app gap keeps it under macOS/Windows). Battery: users report ~9-11h real mixed use vs the ~14h lab web figure — rate on the mixed figure.
